📐 P3 - Rectas y planos en el espacio (10 puntos)

🎯 El acertijo…

Imagina que eres arquitecto y estás diseñando una estructura tridimensional. Tienes tres puntos clave en el espacio: A = (2, −1, 0), B = (1, 2, 3) y C = (−1, 0, 0). Necesitas trazar una viga que pase por A y B, luego levantar un muro perpendicular a esa viga que pase por C, y finalmente calcular qué tan lejos está el punto A de ese muro. ¡La geometría del espacio nunca fue tan práctica!

💡 Estefanía dice: “Las rectas en el espacio se definen con un punto y un vector director, igual que una viga se define por su ancla y su dirección. ¡Piensa en 3D como si fueras un constructor!”

Antes de empezar…

Para resolver este problema necesitamos recordar:

  • Ecuación implícita de una recta en R³: intersección de dos planos
  • Ecuación de un plano: forma general ax+by+cz+d=0ax + by + cz + d = 0ax+by+cz+d=0
  • Producto cruz: para obtener vectores perpendiculares
  • Distancia punto-plano: fórmula estándar

Apartado a) Ecuación implícita de la recta r que contiene A y B (3 puntos)

Paso 1: Vector director de la recta

AB⃗=B−A=(1−2,  2−(−1),  3−0)=(−1,  3,  3)\vec{AB} = B - A = (1-2, \; 2-(-1), \; 3-0) = (-1, \; 3, \; 3)AB=B−A=(1−2,2−(−1),3−0)=(−1,3,3)

El vector director de la recta es v⃗=(−1,3,3)\vec{v} = (-1, 3, 3)v=(−1,3,3).

Paso 2: Ecuación paramétrica de la recta

r:{x=2−λy=−1+3λz=3λr: \begin{cases} x = 2 - \lambda \\ y = -1 + 3\lambda \\ z = 3\lambda \end{cases}r:⎩⎨⎧​x=2−λy=−1+3λz=3λ​

Paso 3: Eliminar el parámetro λ

De la primera ecuación: λ=2−x\lambda = 2 - xλ=2−x

Sustituyendo en la segunda:

y=−1+3(2−x)=−1+6−3xy = -1 + 3(2 - x) = -1 + 6 - 3xy=−1+3(2−x)=−1+6−3x

3x+y−5=0\boxed{3x + y - 5 = 0}3x+y−5=0​

De la tercera ecuación: λ=z3\lambda = \dfrac{z}{3}λ=3z​

Sustituyendo en la primera: x=2−z3x = 2 - \dfrac{z}{3}x=2−3z​… pero mejor usamos directamente:

y=−1+3λ⇒λ=y+13y = -1 + 3\lambda \quad \Rightarrow \quad \lambda = \frac{y+1}{3}y=−1+3λ⇒λ=3y+1​

z=3λ=y+1z = 3\lambda = y + 1z=3λ=y+1

Apartado b) Ecuación del plano π perpendicular a r y que contiene C (4 puntos)

Paso 1: Vector normal al plano

Como π es perpendicular a r, el vector director de r es vector normal a π:

n⃗=v⃗=(−1,3,3)\vec{n} = \vec{v} = (-1, 3, 3)n=v=(−1,3,3)

Paso 2: Usar un punto del plano

El plano contiene el punto C = (−1, 0, 0), así que:

−1(x−(−1))+3(y−0)+3(z−0)=0-1(x - (-1)) + 3(y - 0) + 3(z - 0) = 0−1(x−(−1))+3(y−0)+3(z−0)=0

−(x+1)+3y+3z=0-(x + 1) + 3y + 3z = 0−(x+1)+3y+3z=0

−x−1+3y+3z=0-x - 1 + 3y + 3z = 0−x−1+3y+3z=0

−x+3y+3z−1=0\boxed{-x + 3y + 3z - 1 = 0}−x+3y+3z−1=0​

Verificación

Comprobamos que C satisface la ecuación:

−(−1)+3(0)+3(0)−1=1−1=0✓-(-1) + 3(0) + 3(0) - 1 = 1 - 1 = 0 \checkmark−(−1)+3(0)+3(0)−1=1−1=0✓

✅ Respuesta final

π:−x+3y+3z−1=0\boxed{\pi: -x + 3y + 3z - 1 = 0}π:−x+3y+3z−1=0​

💡 Estefanía dice: “Si el plano es perpendicular a la recta, ¡el vector director de la recta ES el vector normal del plano! Es una de las relaciones más útiles de la geometría 3D.”

💡 Estefanía dice: “Recuerda siempre el valor absoluto en el numerador. ¡La distancia nunca puede ser negativa!”

🧠 Truco de Estefanía

“Cuando calcules la distancia punto-plano, verifica que el punto NO esté en el plano. Si al sustituir obtienes 0, ¡la distancia es cero y el punto está sobre el plano!”

⚠️ Error típico

Olvidar el valor absoluto en la fórmula de distancia. Si el numerador da −6, ponlo como |−6| = 6. ¡La distancia es siempre positiva!

Otro error frecuente es confundir el vector director con el vector normal. En el apartado b), como el plano es perpendicular a la recta, el vector director SÍ es el vector normal. Pero en otros casos, necesitarás calcular el producto cruz para obtener el vector normal.

🎯 ¿Qué llevarte para la vida?

  1. Las rectas en R³ son intersecciones de planos: no puedes definir una recta con una sola ecuación lineal (eso es un plano). Necesitas DOS ecuaciones.

  2. Vector director ↔ Vector normal: esta relación es la clave de todo el problema. Si entiendes cuándo usar cada uno, la mitad del examen está resuelta.

  3. La distancia punto-plano mide cuánto “se desvía” un punto de una superficie: en arquitectura, esto te dice cuánto espacio hay entre un elemento estructural y un punto de referencia.

  4. Siempre verifica tus respuestas: sustituye los puntos en las ecuaciones para comprobar que son correctas. Un segundo de verificación puede ahorrarte varios puntos.
