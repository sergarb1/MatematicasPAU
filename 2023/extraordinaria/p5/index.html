📈 P5 - Estudio de función racional y cálculo integral (10 puntos)

Antes de empezar…

Imagina que trabajas en la gestión de precios de un restaurante. Tu función de beneficio por plato viene dada por una fracción racional. El jefe te pregunta:

  • 🔍 ¿Hay algún precio que cause problemas (discontinuidad)?
  • 📈 ¿Para qué precios el beneficio crece o decrece?
  • 📐 ¿Cuál es el beneficio total acumulado?

💡 Estefanía dice: “Con funciones racionales, lo primero es factorizar numerador y denominador. A veces se cancelan factores y la discontinuidad se vuelve evitable.”

Apartado a) Comprobar que x=−1/2x = -1/2x=−1/2 es discontinuidad evitable (2 puntos)

Resolución paso a paso

Paso 1: Factorizar numerador y denominador

Numerador: −2x2+x+1-2x^2 + x + 1−2x2+x+1

−2x2+x+1=−(2x2−x−1)=−(2x+1)(x−1)-2x^2 + x + 1 = -(2x^2 - x - 1) = -(2x + 1)(x - 1)−2x2+x+1=−(2x2−x−1)=−(2x+1)(x−1)

Denominador: 2x2+5x+22x^2 + 5x + 22x2+5x+2

2x2+5x+2=(2x+1)(x+2)2x^2 + 5x + 2 = (2x + 1)(x + 2)2x2+5x+2=(2x+1)(x+2)

Paso 2: Simplificar

f(x)=−(2x+1)(x−1)(2x+1)(x+2)f(x) = \frac{-(2x + 1)(x - 1)}{(2x + 1)(x + 2)}f(x)=(2x+1)(x+2)−(2x+1)(x−1)​

Cancelamos (2x+1)(2x + 1)(2x+1) siempre que x≠−1/2x \neq -1/2x=−1/2:

f(x)=1−xx+2,x≠−1/2f(x) = \frac{1 - x}{x + 2}, \quad x \neq -1/2f(x)=x+21−x​,x=−1/2

Paso 3: Comprobar que es evitable

El factor (2x+1)(2x + 1)(2x+1) aparece en numerador y denominador, así que x=−1/2x = -1/2x=−1/2 es una discontinuidad evitable. El límite existe:

lim⁡x→−1/2f(x)=1−(−1/2)−1/2+2=3/23/2=1\lim_{x \to -1/2} f(x) = \frac{1 - (-1/2)}{-1/2 + 2} = \frac{3/2}{3/2} = 1limx→−1/2​f(x)=−1/2+21−(−1/2)​=3/23/2​=1

Si definimos f(−1/2)=1f(-1/2) = 1f(−1/2)=1, la función queda continua en ese punto.

x=−1/2 es discontinuidad evitable porque el factor (2x+1) se cancela.\boxed{x = -1/2 \text{ es discontinuidad evitable porque el factor } (2x+1) \text{ se cancela.}}x=−1/2 es discontinuidad evitable porque el factor (2x+1) se cancela.​

Apartado b) Intervalos de crecimiento y decrecimiento (4 puntos)

Resolución paso a paso

Paso 1: Derivada de f(x)=1−xx+2f(x) = \dfrac{1 - x}{x + 2}f(x)=x+21−x​

Usamos la regla del cociente con u=1−xu = 1 - xu=1−x, v=x+2v = x + 2v=x+2:

u′=−1,v′=1u' = -1, \quad v' = 1u′=−1,v′=1

f′(x)=u′v−uv′v2=(−1)(x+2)−(1−x)(1)(x+2)2f'(x) = \frac{u'v - uv'}{v^2} = \frac{(-1)(x + 2) - (1 - x)(1)}{(x + 2)^2}f′(x)=v2u′v−uv′​=(x+2)2(−1)(x+2)−(1−x)(1)​

=−x−2−1+x(x+2)2=−3(x+2)2= \frac{-x - 2 - 1 + x}{(x + 2)^2} = \frac{-3}{(x + 2)^2}=(x+2)2−x−2−1+x​=(x+2)2−3​

Paso 2: Analizar el signo

f′(x)=−3(x+2)2f'(x) = \frac{-3}{(x + 2)^2}f′(x)=(x+2)2−3​

  • El numerador es −3<0-3 < 0−3<0 siempre.
  • El denominador (x+2)2>0(x + 2)^2 > 0(x+2)2>0 siempre (cuadrado de un real no nulo).

Por tanto f′(x)<0f'(x) < 0f′(x)<0 para todo xxx en el dominio.

Paso 3: Conclusión

La función es decreciente en todo su dominio, salvo en los puntos de discontinuidad.

f es decreciente en (−∞,−2)∪(−2,−1/2)∪(−1/2,+∞)\boxed{f \text{ es decreciente en } (-\infty, -2) \cup (-2, -1/2) \cup (-1/2, +\infty)}f es decreciente en (−∞,−2)∪(−2,−1/2)∪(−1/2,+∞)​

💡 Estefanía dice: “Una derivada que nunca cambia de signo significa que la función no tiene extremos locales. Cuidado: la función NO es decreciente en todo R\mathbb{R}R porque tiene discontinuidades.”

Apartado c) Obtener ∫f(x) dx\displaystyle\int f(x)\,dx∫f(x)dx (4 puntos)

Resolución paso a paso

Usamos la forma simplificada f(x)=1−xx+2f(x) = \dfrac{1 - x}{x + 2}f(x)=x+21−x​.

Paso 1: Reescribir la fracción

1−xx+2=−(x+2)+3x+2=−1+3x+2\frac{1 - x}{x + 2} = \frac{-(x + 2) + 3}{x + 2} = -1 + \frac{3}{x + 2}x+21−x​=x+2−(x+2)+3​=−1+x+23​

Paso 2: Integrar término a término

∫f(x) dx=∫(−1+3x+2)dx=−∫1 dx+3∫1x+2 dx\int f(x)\,dx = \int\left(-1 + \frac{3}{x + 2}\right)dx = -\int 1\,dx + 3\int\frac{1}{x + 2}\,dx∫f(x)dx=∫(−1+x+23​)dx=−∫1dx+3∫x+21​dx

=−x+3ln⁡∣x+2∣+C= -x + 3\ln|x + 2| + C=−x+3ln∣x+2∣+C

Resultado final:

∫f(x) dx=3ln⁡∣x+2∣−x+C\boxed{\int f(x)\,dx = 3\ln|x + 2| - x + C}∫f(x)dx=3ln∣x+2∣−x+C​

⚠️ Error típico

Olvidar el valor absoluto en ln⁡∣x+2∣\ln|x + 2|ln∣x+2∣. Sin él, la integral solo estaría definida para x>−2x > -2x>−2, pero el dominio de fff incluye x<−2x < -2x<−2 también.

🧠 Truco de Estefanía

“Cuando tengas una fracción racional donde el grado del numerador es igual al grado del denominador, haz una división larga o reescribe: P(x)Q(x)=cociente+residuoQ(x)\dfrac{P(x)}{Q(x)} = \text{cociente} + \dfrac{\text{residuo}}{Q(x)}Q(x)P(x)​=cociente+Q(x)residuo​. Así la integral se vuelve trivial.”

🎯 ¿Qué llevarte para la vida?

  1. Factoriza siempre numerador y denominador de una racional antes de estudiar discontinuidades.
  2. Discontinuidad evitable = el factor problemático se cancela. El límite existe y la “puedes rellenar”.
  3. Derivada de una racional: regla del cociente. Si la derivada nunca cambia de signo, no hay extremos locales.
  4. Integrar fracciones simples: reescribe como constante + residuo/simple. Luego integra cada parte por separado.
