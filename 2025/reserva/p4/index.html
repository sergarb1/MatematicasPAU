📈 P4 - Analisis (2.5 puntos)

📦 Prisma o funcion racional

Antes de empezar…

El analisis es como una caja de herramientas: tienes derivadas para optimizar, integrales para calcular areas, y funciones para modelar el mundo real.

💡 Estefanía dice: “El analisis no es abstracto. Es como recetas de cocina: tienes una funcion (los ingredientes), la manipulas (la receta), y obtienes un resultado (el plato).”

Tienes dos opciones: 4.1 (prisma triangular) o 4.2 (funcion racional).

📦 OPCION 4.1 - El prisma triangular

El contexto

Un prisma triangular de altura hhh cm, con base de triangulo equilatero de lado xxx cm. Area total = 10 cm².

💡 Estefanía dice: “Un prisma es como una caja de carton: tiene caras, volumen, y un area total que incluye todo. La clave es expressarlo todo en funcion de una sola variable.”

Resolucion

📈 OPCION 4.2 - La funcion racional

La funcion

f(x)=4(x−1)2+xf(x) = \frac{4}{(x-1)^2} + xf(x)=(x−1)24​+x

💡 Estefanía dice: “Una funcion racional es como una receta con un ingrediente prohibido: el denominador no puede ser 0. Si lo es, la funcion ‘explota’ (tiene una asintota vertical).”

Apartado 4.2.1 - 📊 Dominio y asintotas (0.5 pts)

Resolucion

Dominio: Todo xxx real excepto donde el denominador se anula: x≠1x \neq 1x=1.

Dom(f)=R∖{1}\text{Dom}(f) = \mathbb{R} \setminus \{1\}Dom(f)=R∖{1}

Asintota vertical: En x=1x=1x=1 (denominador se anula):

lim⁡x→1f(x)=+∞\lim_{x \to 1} f(x) = +\inftylimx→1​f(x)=+∞

Asintota oblicua: Cuando ∣x∣→∞|x| \to \infty∣x∣→∞, f(x)≈xf(x) \approx xf(x)≈x.

Asintota oblicua: y=x\text{Asintota oblicua: } y = xAsintota oblicua: y=x

💡 Estefanía dice: “Las asintotas son como limites que la funcion nunca toca pero se acerca cada vez mas. La vertical es como un muro, y la oblicua es como una carretera que sigue.”
