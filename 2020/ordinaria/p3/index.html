Problema 3 — Análisis de funciones e integrales 📈

📖 Contexto

Estás analizando el comportamiento de una función que modela la eficiencia de un sistema de ventilación en función de la temperatura. La función tiene singularidades donde el sistema “se rompe”, asíntotas donde se estabiliza, y necesitas calcular el área total de energía consumida en un rango concreto.

f(x)=x2+1x2(x−1)f(x) = \frac{x^2 + 1}{x^2(x - 1)}f(x)=x2(x−1)x2+1​

💡 Estefanía dice: Antes de calcuar nada, mira la función. Tiene un x² en el denominator y un (x-1). Eso te dice exactamente dónde van a estar los problemas: en x = 0 y en x = 1.

a) Dominio y asíntotas (3 pts)

Dominio

La función está definida para todo x tal que el denominator no sea cero:

x2(x−1)≠0⟹x≠0   y   x≠1x^2(x-1) \neq 0 \quad \Longrightarrow \quad x \neq 0 \;\text{ y }\; x \neq 1x2(x−1)=0⟹x=0 y x=1

Dom(f)=R∖{0,1}\boxed{\text{Dom}(f) = \mathbb{R} \setminus \{0, 1\}}Dom(f)=R∖{0,1}​

Asíntotas verticales

Las asíntotas verticales aparecen en los puntos del dominio donde la función tiende a ±∞.

En x = 0:

lim⁡x→0f(x)=lim⁡x→0x2+1x2(x−1)\lim_{x \to 0} f(x) = \lim_{x \to 0} \frac{x^2 + 1}{x^2(x-1)}limx→0​f(x)=limx→0​x2(x−1)x2+1​

El numerator tiende a 1 y el denominator tiende a 0 · (-1) = 0⁻ por la izquierda, 0⁺ · (-1) = 0⁻ por la derecha.

lim⁡x→0f(x)=10=±∞\lim_{x \to 0} f(x) = \frac{1}{0} = \pm\inftylimx→0​f(x)=01​=±∞

→ Asíntota vertical: x = 0 ✅

En x = 1:

lim⁡x→1f(x)=lim⁡x→1x2+1x2(x−1)=21⋅0=±∞\lim_{x \to 1} f(x) = \lim_{x \to 1} \frac{x^2 + 1}{x^2(x-1)} = \frac{2}{1 \cdot 0} = \pm\inftylimx→1​f(x)=limx→1​x2(x−1)x2+1​=1⋅02​=±∞

→ Asíntota vertical: x = 1 ✅

Asíntota horizontal

lim⁡x→±∞f(x)=lim⁡x→±∞x2+1x3−x2=lim⁡x→±∞x2(1+1/x2)x3(1−1/x)=lim⁡x→±∞1x⋅1+1/x21−1/x=0\lim_{x \to \pm\infty} f(x) = \lim_{x \to \pm\infty} \frac{x^2 + 1}{x^3 - x^2} = \lim_{x \to \pm\infty} \frac{x^2(1 + 1/x^2)}{x^3(1 - 1/x)} = \lim_{x \to \pm\infty} \frac{1}{x} \cdot \frac{1 + 1/x^2}{1 - 1/x} = 0limx→±∞​f(x)=limx→±∞​x3−x2x2+1​=limx→±∞​x3(1−1/x)x2(1+1/x2)​=limx→±∞​x1​⋅1−1/x1+1/x2​=0

→ Asíntota horizontal: y = 0 ✅

💡 Estefanía dice: Para asíntotas horizontales, compara grados del numerator y denominator. Si el grado del denominator es mayor, la AH es siempre y = 0.

⚠️ Error típico

Muchos olvidan comprobar x = 0 porque el denominator tiene x² (un cero doble). ¡Un cero doble también produce asíntota vertical! Si el denominator se anula, sea con multiplicidad 1, 2 o 100, hay AV.

b) Integral indefinida y primitiva que pasa por (2, 0) (4 pts)

Paso 1: Fracciones parciales

Descomponemos:

f(x)=x2+1x2(x−1)=Ax+Bx2+Cx−1f(x) = \frac{x^2 + 1}{x^2(x-1)} = \frac{A}{x} + \frac{B}{x^2} + \frac{C}{x-1}f(x)=x2(x−1)x2+1​=xA​+x2B​+x−1C​

Multiplicando por x²(x-1):

x2+1=Ax(x−1)+B(x−1)+Cx2x^2 + 1 = Ax(x-1) + B(x-1) + Cx^2x2+1=Ax(x−1)+B(x−1)+Cx2

Para x = 0: 1 = B(0-1) = -B → B = -1

Para x = 1: 2 = C · 1 → C = 2

Para x = 2: 5 = A · 2 · 1 + (-1)(1) + 2 · 4 = 2A - 1 + 8 = 2A + 7 → A = -1

f(x)=−1x−1x2+2x−1\boxed{f(x) = -\frac{1}{x} - \frac{1}{x^2} + \frac{2}{x-1}}f(x)=−x1​−x21​+x−12​​

Paso 2: Integral indefinida

∫f(x) dx=∫(−1x−1x2+2x−1)dx\int f(x)\,dx = \int\left(-\frac{1}{x} - \frac{1}{x^2} + \frac{2}{x-1}\right)dx∫f(x)dx=∫(−x1​−x21​+x−12​)dx

=−ln⁡∣x∣+1x+2ln⁡∣x−1∣+C= -\ln|x| + \frac{1}{x} + 2\ln|x-1| + C=−ln∣x∣+x1​+2ln∣x−1∣+C

∫f(x) dx=−ln⁡∣x∣+1x+2ln⁡∣x−1∣+C\boxed{\int f(x)\,dx = -\ln|x| + \frac{1}{x} + 2\ln|x-1| + C}∫f(x)dx=−ln∣x∣+x1​+2ln∣x−1∣+C​

Paso 3: Primitiva que pasa por (2, 0)

Llamamos F(x) = -ln|x| + 1/x + 2ln|x-1| + C.

Condición: F(2) = 0.

F(2)=−ln⁡2+12+2ln⁡1+C=−ln⁡2+12+0+C=0F(2) = -\ln 2 + \frac{1}{2} + 2\ln 1 + C = -\ln 2 + \frac{1}{2} + 0 + C = 0F(2)=−ln2+21​+2ln1+C=−ln2+21​+0+C=0

C=ln⁡2−12C = \ln 2 - \frac{1}{2}C=ln2−21​

F(x)=−ln⁡∣x∣+1x+2ln⁡∣x−1∣+ln⁡2−12\boxed{F(x) = -\ln|x| + \frac{1}{x} + 2\ln|x-1| + \ln 2 - \frac{1}{2}}F(x)=−ln∣x∣+x1​+2ln∣x−1∣+ln2−21​​

⚠️ Error típico

Al descomponer en fracciones parciales, el término B/x² aparece porque x² es un factor repetido. Si solo pones A/x, la descomposición está incompleta y la integral sale mal.

c) Área entre f(x), y = 0, x = 2, x = 4 (3 pts)

El área es:

A=∫24∣f(x)∣ dxA = \int_2^4 |f(x)|\,dxA=∫24​∣f(x)∣dx

Para x ∈ [2, 4]: x² > 0 siempre, x - 1 > 0 siempre, y x² + 1 > 0 siempre.

f(x)=x2+1x2(x−1)>0en [2,4]f(x) = \frac{x^2 + 1}{x^2(x-1)} > 0 \quad \text{en } [2, 4]f(x)=x2(x−1)x2+1​>0en [2,4]

Así que |f(x)| = f(x) y:

💡 Estefanía dice: Cuando calculas un área, primero comprueba si la función cambia de signo en el intervalo. Si no cambia, puedes integrar directamente. Si cambia, tienes que partir la integral en subintervalos.

🎯 ¿Qué llevarte para la vida?

  • Las fracciones parciales son tu mejor amigo para integrar fracciones racionales. Aprende bien el algoritmo: factorea el denominator, plantea la ecuación, sustituye valores estratégicos.
  • Un cero repetido en el denominator (x²) requiere un término B/x² adicional en la descomposición. No lo olvides.
  • Para calcular áreas, la clave es: ¿la función cambia de signo? Si no, integra directo. Si sí, parte el intervalo.
