📐 P5 — Distancia de un punto a un plano y simétrico

En un taller de robótica, el técnico quiere calibrar la posición de un sensor P(1, 2, 3) respecto a una superficie de calibración descrita por el plano π: 3x + 2y + z + 4 = 0. Necesita saber la distancia al plano, el punto simétrico y diseñar una nueva superficie de referencia paralela.

a) Distancia de P al plano π (2 pts)

La distancia de un punto a un plano se calcula con la fórmula:

d(P,π)=∣ax0+by0+cz0+d∣a2+b2+c2d(P, \pi) = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}d(P,π)=a2+b2+c2​∣ax0​+by0​+cz0​+d∣​

Sustituyendo P(1, 2, 3) y π: 3x + 2y + z + 4 = 0:

d(P,π)=∣3(1)+2(2)+1(3)+4∣9+4+1=∣3+4+3+4∣14=1414=14d(P, \pi) = \frac{|3(1) + 2(2) + 1(3) + 4|}{\sqrt{9 + 4 + 1}} = \frac{|3 + 4 + 3 + 4|}{\sqrt{14}} = \frac{14}{\sqrt{14}} = \sqrt{14}d(P,π)=9+4+1​∣3(1)+2(2)+1(3)+4∣​=14​∣3+4+3+4∣​=14​14​=14​

💡 Estefanía dice: Si el numerador da 0, el punto está sobre el plano. ¡Revisa siempre que no te dé cero porque significaría que estás calculando una distancia trivial!

⚠️ Error típico

Olvidar el valor absoluto. Si el numerador fuese negativo, sin el módulo obtendrías una distancia negativa, que no tiene sentido geométrico.

b) Simétrico P’ de P respecto a π (5 pts)

Para encontrar el simétrico, necesitamos:

  1. Recta perpendicular a π por P: la dirección de la recta es el vector normal de π, n = (3, 2, 1).

    La paramétrica de la recta es:

    • x = 1 + 3t
    • y = 2 + 2t
    • z = 3 + t

  2. Punto M de intersección de la recta con π: sustituimos en la ecuación del plano:

    3(1+3t)+2(2+2t)+(3+t)+4=03(1 + 3t) + 2(2 + 2t) + (3 + t) + 4 = 03(1+3t)+2(2+2t)+(3+t)+4=0 3+9t+4+4t+3+t+4=03 + 9t + 4 + 4t + 3 + t + 4 = 03+9t+4+4t+3+t+4=0 14t+14=0⇒t=−114t + 14 = 0 \Rightarrow t = -114t+14=0⇒t=−1

    Por tanto: M = (1 + 3(-1), 2 + 2(-1), 3 + (-1)) = (-2, 0, 2)

  3. P’ = 2M − P (M es el punto medio entre P y P’):

    P′=2(−2,0,2)−(1,2,3)=(−4−1,0−2,4−3)=(−5,−2,1)P' = 2(-2, 0, 2) - (1, 2, 3) = (-4 - 1, 0 - 2, 4 - 3) = (-5, -2, 1)P′=2(−2,0,2)−(1,2,3)=(−4−1,0−2,4−3)=(−5,−2,1)

💡 Estefanía dice: Recuerda que M es el punto medio, no un punto más de la recta. La relación es P’ = 2M − P, no P’ = M + (M − P) aunque matemáticamente es lo mismo, es fácil liarse.

⚠️ Error típico

Confundir la dirección de la recta perpendicular. El vector normal del plano es la dirección de la recta perpendicular, ¡no el vectorDirector del plano!

c) Plano π’ que pasa por P’ y es paralelo a π (3 pts)

Un plano paralelo a π tiene la misma ecuación pero distinto término independiente:

π′:3x+2y+z+k=0\pi': 3x + 2y + z + k = 0π′:3x+2y+z+k=0

Sustituimos P’(−5, −2, 1):

3(−5)+2(−2)+1(1)+k=0⇒−15−4+1+k=0⇒k=183(-5) + 2(-2) + 1(1) + k = 0 \Rightarrow -15 - 4 + 1 + k = 0 \Rightarrow k = 183(−5)+2(−2)+1(1)+k=0⇒−15−4+1+k=0⇒k=18

π′:3x+2y+z+18=0\boxed{\pi': 3x + 2y + z + 18 = 0}π′:3x+2y+z+18=0​

💡 Estefanía dice: Los planos paralelos tienen los mismos coeficientes de x, y, z. Solo cambia el término independiente. ¡Es un atajo muy rápido para comprobar!

🎯 ¿Qué llevarte para la vida?

  • La distancia de un punto a un plano mide cuánto “lejos” está de una superficie: úsalo para evaluar si un componente mecánico está bien posicionado.
  • El simétrico te da el reflejo exacto: en óptica y robótica, saber dónde estaría el “espejo” de un punto respecto a una superficie es fundamental para el diseño de sistemas de referencia.
  • Los planos paralelos son como capas de una cebolla: mismos vectores normales, distinta ubicación. En ingeniería se usan para definir superficies de referencia a diferentes alturas.
