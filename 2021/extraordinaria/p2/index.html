📐 Pregunta 2 — Rectas, Planos y Volúmenes

Contexto

Un arquitecto está diseñando una pirámide de cristal para un museo. Necesita calcular las intersecciones entre las paredes rectas y el suelo inclinado para determinar la base del tetraedro. Tú eres su asistente matemático: tus ecuaciones son sus planos de construcción.

Enunciado

Se consideran:

  • Recta (r): (\begin{cases} x + y - 1 = 0 \ 2x - z - 1 = 0 \end{cases})

  • Recta (s): (\dfrac{x-1}{1} = \dfrac{y}{-1} = \dfrac{z}{2})

  • Plano (\pi): (x + my + z = 2)

a) Determinar la posición relativa de las rectas (r) y (s) (4 puntos)

b) Calcular el valor de (m) para que la recta (r) pertenezca al plano (\pi) (3 puntos)

c) Para (m = 2), hallar los puntos (A), (B) y (C) de intersección de (\pi) con los ejes, y calcular el volumen del tetraedro (ABC-P), siendo (P(2, 2, 2)) (3 puntos)

Resolución paso a paso

Apartado a) Posición relativa de (r) y (s)

Paso 1: Dirección de (r)

La recta (r) viene dada como intersección de dos planos. El vector director es el producto cruz de los vectores normales:

n1⃗=(1,1,0),n2⃗=(2,0,−1)\vec{n_1} = (1, 1, 0), \quad \vec{n_2} = (2, 0, -1)n1​​=(1,1,0),n2​​=(2,0,−1) dr⃗=n1⃗×n2⃗=∣i⃗j⃗k⃗11020−1∣=(−1,1,−2)\vec{d_r} = \vec{n_1} \times \vec{n_2} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & 1 & 0 \\ 2 & 0 & -1 \end{vmatrix} = (-1, 1, -2)dr​​=n1​​×n2​​=​i12​j​10​k0−1​​=(−1,1,−2)

Paso 2: Dirección de (s)

La recta (s) viene dada en forma canónica con director (\vec{d_s} = (1, -1, 2)).

Paso 3: Comparar direcciones

Observamos que:

dr⃗=(−1,1,−2)=−1⋅(1,−1,2)=−1⋅ds⃗\vec{d_r} = (-1, 1, -2) = -1 \cdot (1, -1, 2) = -1 \cdot \vec{d_s}dr​​=(−1,1,−2)=−1⋅(1,−1,2)=−1⋅ds​​

Los vectores directores son paralelos (uno es múltiplo del otro). Las rectas son paralelas.

Paso 4: Verificar si coinciden

Tomamos un punto de cada recta y comprobamos si están en la otra.

Punto de (r): Si (y = 0), entonces (x = 1) y (z = 2(1) - 1 = 1). Punto (A_r(1, 0, 1)).

¿Está (A_r) en (s)? Comprobamos:

1−11=0,0−1=0,12=0.5\frac{1-1}{1} = 0, \quad \frac{0}{-1} = 0, \quad \frac{1}{2} = 0.511−1​=0,−10​=0,21​=0.5

Como (0 \neq 0.5), el punto no está en (s).

Las rectas r y s son paralelas y distintas.\boxed{\text{Las rectas } r \text{ y } s \text{ son paralelas y distintas.}}Las rectas r y s son paralelas y distintas.​

💡 Estefanía dice: Cuando las direcciones son proporcionales, las rectas son paralelas o coincidentes. Siempre comprueba un punto para desambiguar.

Apartado b) Valor de (m) para que (r \subset \pi)

Para que (r) esté en (\pi), basta con que dos puntos de (r) pertenezcan a (\pi) (ya que una recta queda determinada por dos puntos).

Punto 1 de (r): (A_r(1, 0, 1)) (obtenido antes).

Sustituyendo en (\pi): (1 + m(0) + 1 = 2 \Rightarrow 2 = 2). ✓ (Siempre se cumple)

Punto 2 de (r): Si (z = 0), entonces (2x = 1 \Rightarrow x = \frac{1}{2}) y (y = 1 - x = \frac{1}{2}). Punto (B_r\left(\frac{1}{2}, \frac{1}{2}, 0\right)).

Sustituyendo en (\pi):

12+m⋅12+0=2  ⟹  1+m2=2  ⟹  1+m=4\frac{1}{2} + m \cdot \frac{1}{2} + 0 = 2 \implies \frac{1 + m}{2} = 2 \implies 1 + m = 421​+m⋅21​+0=2⟹21+m​=2⟹1+m=4 m=3\boxed{m = 3}m=3​

💡 Estefanía dice: Si un punto de la recta ya cumple la ecuación del plano automáticamente, solo necesitas el segundo punto para determinar (m). Ahorra tiempo.

Apartado c) Intersecciones con ejes y volumen para (m = 2)

Con (m = 2), el plano es: (x + 2y + z = 2).

Paso 1: Intersección con el eje (X) ((y = 0, z = 0))

x+0+0=2  ⟹  x=2x + 0 + 0 = 2 \implies x = 2x+0+0=2⟹x=2 A=(2,0,0)A = (2, 0, 0)A=(2,0,0)

Paso 2: Intersección con el eje (Y) ((x = 0, z = 0))

0+2y+0=2  ⟹  y=10 + 2y + 0 = 2 \implies y = 10+2y+0=2⟹y=1 B=(0,1,0)B = (0, 1, 0)B=(0,1,0)

Paso 3: Intersección con el eje (Z) ((x = 0, y = 0))

0+0+z=2  ⟹  z=20 + 0 + z = 2 \implies z = 20+0+z=2⟹z=2 C=(0,0,2)C = (0, 0, 2)C=(0,0,2)

💡 Estefanía dice: El volumen del tetraedro es siempre (\frac{1}{6}) del valor absoluto del determinante formado por los tres vectores desde un vértice común. Memoriza la fórmula; es tu mejor aliada en geometría.

⚠️ Error típico

Calcular el volumen con (\frac{1}{3}) en vez de (\frac{1}{6}).

El volumen de un tetraedro es (\frac{1}{6}|\det|), no (\frac{1}{3}). El (\frac{1}{3}) aparece en el volumen de una pirámide ((V = \frac{1}{3} \cdot \text{base} \cdot \text{altura})), pero cuando calculas directamente con el determinante, el factor es (\frac{1}{6}). ¡No los confundas!

🎯 ¿Qué llevarte para la vida?

Las rectas paralelas nunca se cruzan, como los caminos de dos personas que caminan en la misma dirección pero nunca se encuentran. Pero cuando un plano corta al espacio, crea formas nuevas — triángulos, tetraedros — que tienen volumen real. A veces, necesitas un corte transversal para ver la profundidad de las cosas.
