📈 P5 - Función con Parámetro: Mínimo y Áreas (10 puntos)

🎢 La montaña rusa cuadrática

Antes de empezar…

Imagina que diseñas una montaña rusa con ecuación h(x)=ax+x2h(x) = ax + x^2h(x)=ax+x2. El parámetro aaa controla la inclinación inicial. Tu jefe te pregunta:

  • 🎯 ¿Qué valor de a pone el fondo del valle en x=−3/4x = -3/4x=−3/4?
  • 📊 ¿Cómo se ven las gráficas de h y h’?
  • 📐 ¿Qué área hay entre las dos curvas?

💡 Estefanía dice: “Una parábola con x2x^2x2 siempre abre hacia arriba. El parámetro aaa solo mueve dónde está el fondo.”

Apartado a) - 🎯 Encontrar a para mínimo en x = -3/4 (3 puntos)

El enunciado en 5 segundos

🤔 ¿Qué valor de a hace que el mínimo esté en x=−3/4x = -3/4x=−3/4?

La lógica

Para un mínimo relativo, necesitamos h′(x)=0h'(x) = 0h′(x)=0 y h′′(x)>0h''(x) > 0h′′(x)>0.

Resolución paso a paso

h(x)=ax+x2h(x) = ax + x^2h(x)=ax+x2

h′(x)=a+2xh'(x) = a + 2xh′(x)=a+2x

Para mínimo en x=−3/4x = -3/4x=−3/4:

h′(−3/4)=0⇒a+2(−3/4)=0⇒a−3/2=0h'(-3/4) = 0 \Rightarrow a + 2(-3/4) = 0 \Rightarrow a - 3/2 = 0h′(−3/4)=0⇒a+2(−3/4)=0⇒a−3/2=0

a=32\boxed{a = \frac{3}{2}}a=23​​

Comprobamos: h′′(x)=2>0h''(x) = 2 > 0h′′(x)=2>0 siempre → efectivamente es un mínimo.

🧠 Truco de Estefanía

“Deriva, iguala a cero, despeja. Si la segunda derivada es positiva, es mínimo.”

🎯 ¿Qué llevarte para la vida?

  1. Mínimo = derivada primera = 0 y segunda derivada > 0
  2. La derivada cruza el eje x exactamente donde la función tiene extremo
  3. Área entre curvas = integral de (arriba - abajo) entre intersecciones
  4. Los parámetros se determinan con condiciones específicas (como el punto de mínimo)
  5. Siempre dibuja antes de integrar — te ayuda a ver quién va arriba
