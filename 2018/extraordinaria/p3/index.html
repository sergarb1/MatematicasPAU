Opcion A — Problema 3: Analisis de funcion con parametros 📈

📖 Contexto

Estas analizando el comportamiento de un sistema de control donde la posicion de un robot se describe por una funcion que depende de tres parametros de calibracion aaa, bbb, ccc. Necesitas encontrar la relacion entre los parametros cuando la funcion toma un valor conocido, cuando la tangente en un punto es horizontal, y calcular una integral definida que representa la energia acumulada.

La funcion es:

f(x)=ax2+bx+ccos⁡(x)f(x) = ax^2 + bx + c\cos(x)f(x)=ax2+bx+ccos(x)

💡 Estefania dice: Las funciones con parametros son comunes en examenes. La clave es usar las condiciones dadas (valores de la funcion, derivadas) para establecer ecuaciones entre los parametros.

a) Relacion entre a, b, c sabiendo que f(1) = 22 (2 pts)

Paso 1: Evaluamos f(1)

f(1)=a(1)2+b(1)+ccos⁡(1)=a+b+ccos⁡(1)f(1) = a(1)^2 + b(1) + c\cos(1) = a + b + c\cos(1)f(1)=a(1)2+b(1)+ccos(1)=a+b+ccos(1)

Paso 2: Igualamos a 22

a+b+ccos⁡(1)=22a + b + c\cos(1) = 22a+b+ccos(1)=22

Resultado

a+b+ccos⁡(1)=22\boxed{a + b + c\cos(1) = 22}a+b+ccos(1)=22​

💡 Estefania dice: Este es el paso mas directo del problema. Simplemente evalua la funcion en el punto dado y establece la ecuacion.

⚠️ Error tipico

Confundir cos⁡(1)\cos(1)cos(1) con cos⁡(π)=−1\cos(\pi) = -1cos(π)=−1. El valor 111 esta en radianes, no en grados. cos⁡(1)≈0.5403\cos(1) \approx 0.5403cos(1)≈0.5403.

b) Relacion para que la tangente en P sea horizontal (abscisa x = 1) (4 pts)

Paso 1: Calculamos la derivada

f′(x)=2ax+b−csin⁡(x)f'(x) = 2ax + b - c\sin(x)f′(x)=2ax+b−csin(x)

Paso 2: Condicion de tangente horizontal

La recta tangente es horizontal cuando f′(1)=0f'(1) = 0f′(1)=0:

f′(1)=2a(1)+b−csin⁡(1)=0f'(1) = 2a(1) + b - c\sin(1) = 0f′(1)=2a(1)+b−csin(1)=0

2a+b−csin⁡(1)=02a + b - c\sin(1) = 02a+b−csin(1)=0

Resultado

2a+b−csin⁡(1)=0\boxed{2a + b - c\sin(1) = 0}2a+b−csin(1)=0​

💡 Estefania dice: Una tangente horizontal significa que la derivada se anula en ese punto. Es el punto critico de la funcion.

⚠️ Error tipico

Olvidar que cos⁡′(x)=−sin⁡(x)\cos'(x) = -\sin(x)cos′(x)=−sin(x), no sin⁡(x)\sin(x)sin(x). El signo negativo es comunmente olvidado y cambia completamente el resultado.

c) Calculo de ∫01xcos⁡(x) dx\int_0^1 x\cos(x)\,dx∫01​xcos(x)dx (4 pts)

Paso 1: Integracion por partes

Usamos la formula ∫u dv=uv−∫v du\int u\,dv = uv - \int v\,du∫udv=uv−∫vdu con:

u=x  ⟹  du=dxu = x \implies du = dxu=x⟹du=dx dv=cos⁡(x) dx  ⟹  v=sin⁡(x)dv = \cos(x)\,dx \implies v = \sin(x)dv=cos(x)dx⟹v=sin(x)

Paso 2: Aplicamos la formula

∫01xcos⁡(x) dx=[xsin⁡(x)]01−∫01sin⁡(x) dx\int_0^1 x\cos(x)\,dx = \Big[x\sin(x)\Big]_0^1 - \int_0^1 \sin(x)\,dx∫01​xcos(x)dx=[xsin(x)]01​−∫01​sin(x)dx

Paso 3: Evaluamos

=(1⋅sin⁡(1)−0⋅sin⁡(0))−[−cos⁡(x)]01= \Big(1 \cdot \sin(1) - 0 \cdot \sin(0)\Big) - \Big[-\cos(x)\Big]_0^1=(1⋅sin(1)−0⋅sin(0))−[−cos(x)]01​

=sin⁡(1)−(−cos⁡(1)+cos⁡(0))= \sin(1) - \Big(-\cos(1) + \cos(0)\Big)=sin(1)−(−cos(1)+cos(0))

=sin⁡(1)+cos⁡(1)−1= \sin(1) + \cos(1) - 1=sin(1)+cos(1)−1

Paso 4: Valor numerico

sin⁡(1)≈0.8415,cos⁡(1)≈0.5403\sin(1) \approx 0.8415, \quad \cos(1) \approx 0.5403sin(1)≈0.8415,cos(1)≈0.5403

∫01xcos⁡(x) dx≈0.8415+0.5403−1\int_0^1 x\cos(x)\,dx \approx 0.8415 + 0.5403 - 1∫01​xcos(x)dx≈0.8415+0.5403−1

∫01xcos⁡(x) dx=sin⁡(1)+cos⁡(1)−1≈0.382\boxed{\int_0^1 x\cos(x)\,dx = \sin(1) + \cos(1) - 1 \approx 0.382}∫01​xcos(x)dx=sin(1)+cos(1)−1≈0.382​

💡 Estefania dice: La integracion por partes es ideal para productos de funciones polinomicas con trigonometricas. Recuerda la regla LIATE: Logaritmicas, Inversas trigonometricas, Algebraicas, Trigonometricas, Exponenciales para elegir uuu.

⚠️ Error tipico

Olvidar el signo negativo al integrar sin⁡(x)\sin(x)sin(x). La integral de sin⁡(x)\sin(x)sin(x) es −cos⁡(x)-\cos(x)−cos(x), no cos⁡(x)\cos(x)cos(x). Este error cambia completamente el resultado final.

🎯 ¿Que llevarte para la vida?

  • Evaluar es el primer paso: Cuando una funcion toma un valor conocido, sustituye y establece la ecuacion. Es el paso mas facil del problema.
  • Tangente horizontal = derivada cero: Si la tangente es horizontal, la derivada se anula en ese punto. Es la condicion fundamental del calculo.
  • Integracion por partes es universal: Para productos de polinomios con trigonometricas, exponentiales o logaritmos, la integracion por partes siempre funciona.
