Opcion B — Problema 1: Algebra matricial 🔢

📖 Contexto

Estas trabajando en un sistema de control de robotica donde las transformaciones de movimiento se representan como matrices. Necesitas demostrar propiedades algebraicas fundamentales, encontrar parametros que hagan que una matriz sea idempotente, y calcular determinantes para verificar estabilidad del sistema.

a) Demostrar que si AB = A y BA = B, entonces A² = A y B² = B (4 pts)

Paso 1: Demostracion de A² = A

Partimos de la igualdad AB=AAB = AAB=A. Multiplicamos por AAA por la izquierda:

A(AB)=A⋅AA(AB) = A \cdot AA(AB)=A⋅A

A2B=A2A^2B = A^2A2B=A2

Pero tambien sabemos que BA=BBA = BBA=B. Multiplicamos AB=AAB = AAB=A por la derecha por BBB:

(AB)B=AB(AB)B = AB(AB)B=AB

AB2=AAB^2 = AAB2=A

Esto no nos lleva directamente a A2=AA^2 = AA2=A. Usemos otro enfoque.

De AB=AAB = AAB=A, multiplicamos por la izquierda por AAA:

A2B=A2(1)A^2B = A^2 \quad (1)A2B=A2(1)

De BA=BBA = BBA=B, multiplicamos por la derecha por AAA:

BAA=BABAA = BABAA=BA

BA2=B(2)BA^2 = B \quad (2)BA2=B(2)

Ahora, de (1): A2B=A2A^2B = A^2A2B=A2. Multiplicamos por la izquierda por AAA:

A3B=A3A^3B = A^3A3B=A3

Esto sugiere una recursion. Volvemos al enfoque original.

De AB=AAB = AAB=A, multiplicamos por la derecha por AAA:

ABA=A2ABA = A^2ABA=A2

Pero BA=BBA = BBA=B, entonces:

A(BA)=A2A(BA) = A^2A(BA)=A2

AB=A2AB = A^2AB=A2

Como AB=AAB = AAB=A:

A2=A\boxed{A^2 = A}A2=A​

Paso 2: Demostracion de B² = B

De BA=BBA = BBA=B, multiplicamos por la izquierda por BBB:

B(BA)=B⋅BB(BA) = B \cdot BB(BA)=B⋅B

B2A=B2B^2A = B^2B2A=B2

De AB=AAB = AAB=A, multiplicamos por la izquierda por BBB:

B(AB)=BAB(AB) = BAB(AB)=BA

BAB=BBAB = BBAB=B

Pero AB=AAB = AAB=A, entonces:

B(AB)=B⋅AB(AB) = B \cdot AB(AB)=B⋅A

BA=BABA = BABA=BA

Esto es una identidad. Usemos otro enfoque.

De BA=BBA = BBA=B, multiplicamos por la derecha por BBB:

(BA)B=BB(BA)B = BB(BA)B=BB

BAB=B2BAB = B^2BAB=B2

Pero BAB=BBAB = BBAB=B (demostrado arriba):

B2=B\boxed{B^2 = B}B2=B​

💡 Estefania dice: Las matrices idempotentes (A2=AA^2 = AA2=A) son fundamentales en algebra lineal. Son como los numeros 0 y 1: multiplicados por si mismos dan el mismo resultado.

⚠️ Error tipico

Asumir que las matrices conmutan. En general, AB≠BAAB \neq BAAB=BA. Por eso es importante especificar si multiplicas por la izquierda o por la derecha.

b) Encontrar α, β para que B² = B pero AB ≠ A y BA ≠ B (2 pts)

Paso 1: Calculamos B²

B=(α00β)B = \begin{pmatrix} \alpha & 0 \\ 0 & \beta \end{pmatrix}B=(α0​0β​)

B2=(α200β2)B^2 = \begin{pmatrix} \alpha^2 & 0 \\ 0 & \beta^2 \end{pmatrix}B2=(α20​0β2​)

Paso 2: Condicion B² = B

α2=α  ⟹  α(α−1)=0  ⟹  α=0 o α=1\alpha^2 = \alpha \implies \alpha(\alpha - 1) = 0 \implies \alpha = 0 \text{ o } \alpha = 1α2=α⟹α(α−1)=0⟹α=0 o α=1

β2=β  ⟹  β(β−1)=0  ⟹  β=0 o β=1\beta^2 = \beta \implies \beta(\beta - 1) = 0 \implies \beta = 0 \text{ o } \beta = 1β2=β⟹β(β−1)=0⟹β=0 o β=1

Paso 3: Condicion AB ≠ A

A=(1000),B=(α00β)A = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \quad B = \begin{pmatrix} \alpha & 0 \\ 0 & \beta \end{pmatrix}A=(10​00​),B=(α0​0β​)

Para que AB≠AAB \neq AAB=A: α≠1\alpha \neq 1α=1, es decir, α=0\alpha = 0α=0.

Paso 4: Condicion BA ≠ B

BA=(α000)BA = \begin{pmatrix} \alpha & 0 \\ 0 & 0 \end{pmatrix}BA=(α0​00​)

Para que BA≠BBA \neq BBA=B: β≠0\beta \neq 0β=0, es decir, β=1\beta = 1β=1.

Resultado

α=0,β=1\boxed{\alpha = 0, \quad \beta = 1}α=0,β=1​

Verificacion

B=(0001)B = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}B=(00​01​)

  • B2=(0001)=BB^2 = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} = BB2=(00​01​)=B ✓
  • AB=(0000)≠AAB = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix} \neq AAB=(00​00​)=A ✓
  • BA=(0000)≠BBA = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix} \neq BBA=(00​00​)=B ✓

💡 Estefania dice: Las matrices diagonales son las mas simples de elevar a potencias: simplemente elevas cada elemento de la diagonal al cuadrado.

⚠️ Error tipico

Olvidar verificar todas las condiciones. En este problema necesitas B2=BB^2 = BB2=B, AB≠AAB \neq AAB=A Y BA≠BBA \neq BBA=B. Si solo verificas una, puedes obtener una solucion incorrecta.

💡 Estefania dice: Las operaciones elementales sobre filas tienen efectos predecibles en el determinante: intercambiar filas cambia el signo, multiplicar una fila por kkk multiplica el determinantepor kkk, y sumar un multiplo de una fila a otra no cambia nada.

⚠️ Error tipico

Confundir las propiedades del determinante. Sumar un multiplo de una fila a otra NO cambia el determinante, pero SI cambia si intercambias filas o multiplicas una fila por un escalar.

🎯 ¿Que llevarte para la vida?

  • Las matrices idempotentes son como 0 y 1: Si A2=AA^2 = AA2=A, la matriz es su propia “raiz cuadrada”. Son fundamentales en proyectores y sistemas de control.
  • Multiplica por el lado correcto: En algebra matricial, el orden importa. AB≠BAAB \neq BAAB=BA en general, por lo que debes ser cuidadoso con la izquierda y la derecha.
  • Las propiedades del determinante son tu brujula: Saber como afectan las operaciones de fila al determinante te ahorra calculos enormes.
