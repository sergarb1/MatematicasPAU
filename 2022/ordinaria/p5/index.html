📈 P5 — Análisis de una función racional

Imagina que estás modelizando el comportamiento de un circuito eléctrico donde la impedancia depende de la frecuencia. La función que describe ese comportamiento es una función racional: necesitas entenderla a fondo para predecir dónde el sistema se vuelve inestable y cómo se comporta fuera de esas zonas.

Vamos a analizar la función:

f(x)=x2+3x2−4f(x) = \frac{x^2 + 3}{x^2 - 4}f(x)=x2−4x2+3​

a) Dominio y puntos de corte con los ejes (1 pt)

Dominio

La función es una fracción, así que el denominador no puede ser cero:

x2−4≠0  ⟹  (x−2)(x+2)≠0  ⟹  x≠2∧x≠−2x^2 - 4 \neq 0 \implies (x-2)(x+2) \neq 0 \implies x \neq 2 \land x \neq -2x2−4=0⟹(x−2)(x+2)=0⟹x=2∧x=−2

Df=R∖{−2,2}\boxed{D_f = \mathbb{R} \setminus \{-2, 2\}}Df​=R∖{−2,2}​

Punto de corte con el eje Y (ordenada al origen)

Evaluamos f(0)f(0)f(0):

f(0)=02+302−4=3−4=−34f(0) = \frac{0^2 + 3}{0^2 - 4} = \frac{3}{-4} = -\frac{3}{4}f(0)=02−402+3​=−43​=−43​

El punto de corte con el eje Y es (0, −34)\left(0,\ -\dfrac{3}{4}\right)(0, −43​).

Puntos de corte con el eje X (raíces)

Igualamos f(x)=0f(x) = 0f(x)=0:

x2+3x2−4=0  ⟹  x2+3=0\frac{x^2 + 3}{x^2 - 4} = 0 \implies x^2 + 3 = 0x2−4x2+3​=0⟹x2+3=0

Pero x2+3≥3>0x^2 + 3 \geq 3 > 0x2+3≥3>0 para todo x∈Rx \in \mathbb{R}x∈R. No hay solución real.

No corta al eje X\boxed{\text{No corta al eje X}}No corta al eje X​

💡 Estefanía dice: Una función racional solo corta al eje X si el numerador tiene raíces reales que no sean también raíces del denominador. Si el numerador es siempre positivo (como aquí), simplemente no lo corta.

⚠️ Error típico

Decir que f(x)=0f(x) = 0f(x)=0 cuando x2+3=0x^2 + 3 = 0x2+3=0 da x=±3x = \pm\sqrt{3}x=±3​. ¡Esos son imaginarios! En cálculo de una variable real, si la ecuación no tiene solución real, la función no corta al eje X.

b) Asíntotas (2 pts)

Asíntotas verticales (AV)

Se producen en los puntos donde el denominador se anula pero el numerador no:

En x=−2x = -2x=−2: (−2)2+3(−2)2−4=70→∞\quad \dfrac{(-2)^2 + 3}{(-2)^2 - 4} = \dfrac{7}{0} \to \infty(−2)2−4(−2)2+3​=07​→∞ ✓

En x=2x = 2x=2: 22+322−4=70→∞\quad \dfrac{2^2 + 3}{2^2 - 4} = \dfrac{7}{0} \to \infty22−422+3​=07​→∞ ✓

AV: x=−2yx=2\boxed{\text{AV: } x = -2 \quad \text{y} \quad x = 2}AV: x=−2yx=2​

Asíntota horizontal (AH)

Calculamos el límite cuando x→±∞x \to \pm\inftyx→±∞. Como el grado del numerador y del denominador son iguales (ambos grado 2):

lim⁡x→±∞x2+3x2−4=11=1\lim_{x \to \pm\infty} \frac{x^2 + 3}{x^2 - 4} = \frac{1}{1} = 1limx→±∞​x2−4x2+3​=11​=1

AH: y=1\boxed{\text{AH: } y = 1}AH: y=1​

💡 Estefanía dice: Cuando numerador y denominador tienen el mismo grado, la AH es el cociente de los coeficientes principales. Si el grado del numerador fuera menor, la AH sería y=0y = 0y=0.

⚠️ Error típico

Confundir asíntota vertical con discontinuidad evitable. Aquí x=±2x = \pm 2x=±2 son discontinuidades esenciales (la función tiende a ±∞\pm\infty±∞), no puntos de salto finito.

c) Intervalos de crecimiento, decrecimiento y extremos (3 pts)

Calculamos la derivada usando la regla del cociente:

f′(x)=(2x)(x2−4)−(x2+3)(2x)(x2−4)2f'(x) = \frac{(2x)(x^2-4) - (x^2+3)(2x)}{(x^2-4)^2}f′(x)=(x2−4)2(2x)(x2−4)−(x2+3)(2x)​

Simplificamos el numerador:

2x(x2−4)−2x(x2+3)=2x3−8x−2x3−6x=−14x2x(x^2-4) - 2x(x^2+3) = 2x^3 - 8x - 2x^3 - 6x = -14x2x(x2−4)−2x(x2+3)=2x3−8x−2x3−6x=−14x

⚠️ Error típico

Olvidar que las asíntotas verticales crean “particiones” en la recta real. No puedes escribir ”fff crece en (−∞,0)(-\infty, 0)(−∞,0)” porque hay un hueco en x=−2x = -2x=−2. Siempre separa los intervalos por las asíntotas.

d) Primitiva de f(x) (4 pts)

Necesitamos calcular:

∫x2+3x2−4 dx\int \frac{x^2 + 3}{x^2 - 4}\, dx∫x2−4x2+3​dx

Paso 1: División polinómica (o reformulación)

Como el grado del numerador iguala al del denominador, hacemos:

x2+3x2−4=(x2−4)+7x2−4=1+7x2−4\frac{x^2 + 3}{x^2 - 4} = \frac{(x^2 - 4) + 7}{x^2 - 4} = 1 + \frac{7}{x^2 - 4}x2−4x2+3​=x2−4(x2−4)+7​=1+x2−47​

Paso 2: Fracciones parciales

Factorizamos x2−4=(x−2)(x+2)x^2 - 4 = (x-2)(x+2)x2−4=(x−2)(x+2) y planteamos:

7(x−2)(x+2)=Ax−2+Bx+2\frac{7}{(x-2)(x+2)} = \frac{A}{x-2} + \frac{B}{x+2}(x−2)(x+2)7​=x−2A​+x+2B​

Multiplicando por (x−2)(x+2)(x-2)(x+2)(x−2)(x+2):

7=A(x+2)+B(x−2)7 = A(x+2) + B(x-2)7=A(x+2)+B(x−2)

  • Para x=2x = 2x=2: 7=4A  ⟹  A=747 = 4A \implies A = \dfrac{7}{4}7=4A⟹A=47​
  • Para x=−2x = -2x=−2: 7=−4B  ⟹  B=−747 = -4B \implies B = -\dfrac{7}{4}7=−4B⟹B=−47​

🎯 ¿Qué llevarte para la vida?

Las funciones racionales aparecen en circuitos eléctricos, filtros de audio, resonancia mecánica y en cualquier sistema donde dos fuerzas compiten (como la señal que entra vs. la que se amortigua). Saber leer sus asíntotas te dice dónde el sistema se vuelve inestable (asíntotas verticales = frecuencias de resonancia) y cómo se comporta a largo plazo (asíntota horizontal = estado estacionario). Es como tener el mapa del comportamiento de un sistema sin necesidad de simularlo.
